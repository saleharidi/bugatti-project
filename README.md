# Bugatti Showcase

A website that showcases bugatti's famous cars.

### Technologies
* HTML
* CSS
* JavaScript

### How to use:

1. Open the website on your browser from github.
2. Scroll and browse some of bugatti's cars.

### Features

* carousel to shocase the cars.
* An engine button to hear the sound of the engine.
* A gallery for each car with its specifications.
